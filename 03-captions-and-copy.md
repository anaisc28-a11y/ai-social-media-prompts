# 03 · Captions & copy

---

## 3.1 · Caption with a job

```text
Write a caption for this post: {{describe post}}. Goal: {{saves / comments / clicks / DMs}}.
Give 3 versions: short (≤150 chars), medium (≤600), long storytelling (≤1500).
Each version must have: a first line that works as a hook before "...more", one specific detail, and a CTA aligned to the goal.
No hashtag walls: suggest max 5 relevant hashtags separately.
Respond in {{language}}.
```

## 3.2 · Carousel builder (save-worthy)

```text
Create a {{8-10}} slide carousel about {{topic}}.
Slide 1: hook title (max 8 words) + subtitle. Slides 2-n: one idea per slide, max 25 words. Last slide: summary + CTA.
Add visual direction per slide (layout, highlight word, icon idea) so a designer or Canva can build it.
Respond in {{language}}.
```

## 3.3 · One idea → 6 formats (repurposing)

```text
Core idea: {{idea}}. Turn it into: 1 Reel script (30s), 1 carousel outline, 3 Stories with interaction stickers, 1 LinkedIn post, 1 newsletter paragraph, 1 TikTok text-on-screen version.
Keep the message identical, adapt the tone to each platform.
Respond in {{language}}.
```

## 3.4 · CTA bank

```text
Write 20 CTAs for {{brand}} grouped by goal: comments, saves, shares, DMs with keyword "{{keyword}}", link clicks.
Avoid "link in bio" clichés unless needed. Mark the 5 with the lowest friction.
Respond in {{language}}.
```

## 3.5 · Stories sequence that sells softly

```text
Design a 7-Story sequence to present {{offer}} to warm followers.
Structure: relatable moment → problem → my experience → solution → proof → offer → poll/DM CTA.
For each Story: text, sticker to use, visual idea. Tone: from the Brand Voice Card, never pushy.
Respond in {{language}}.
```

## 3.6 · Copy editor (make it human)

```text
Edit this AI-sounding copy so it sounds like a real person from our brand wrote it: {{copy}}
Remove: buzzwords, triple adjectives, "in today's world", em-dash overuse, perfect symmetry.
Add: one concrete detail, one imperfect/real sentence, rhythm changes.
Show the edited version and list the 5 biggest changes.
Respond in {{language}}.
```
